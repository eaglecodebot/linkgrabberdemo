Trial reuses a matching tab without reloading it. If none is open, it navigates your current tab, including a blank New Tab page, to this URL. Cancel & Refund reuses a matching tab or navigates your current tab to this URL. It dismisses the captured tooltip if present, then opens the selected Premium Career subscription. Opens after Confirm cancel (picker action 6), once the cancellation screen changes. The runner then clicks Submit and Contact LinkedIn Support. Optional. One website origin per line. If an unlisted website opens during a run, the extension pauses and lets you grant access.
200 ms is the faster default. This is the time a control must remain still before use. Keep Wait per step high enough for slow pages; it is a maximum timeout, not a delay added to every step.

Pincode field

A run picks one value and keeps it through refreshes, pauses and retries. The expanded default has 56 entries. For real billing, enter the pincode that belongs to your billing address. The captured “Pin code” label is used automatically. If the website changes, collect the field with the separate Private Element Picker. A CSS override can be entered here if needed.
